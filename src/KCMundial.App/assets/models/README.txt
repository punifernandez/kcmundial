YuNet face detection model (ONNX).

Download the model file and place it here with this exact name:
  face_detection_yunet_2023mar.onnx

Source (do not fetch at runtime; copy once to this folder):
  https://huggingface.co/opencv/face_detection_yunet/resolve/main/face_detection_yunet_2023mar.onnx

If the file is missing, the app falls back to Haar cascade face detection.
